# Agent Network v1 coverage

Status is implementation evidence, not a claim that a screen completes the proposal. No paid service or production migration is enabled by this Test release.

| Proposal area | Current implementation | Remaining for full paid v1 |
| --- | --- | --- |
| Agent creation | Templates, saved workflow adapter, immutable snapshots, local test, signed invitation | Scoped private data/tool bundles and service evaluations |
| Identity | Dedicated Koinos-compatible free-service identity; sequence and signature validation | On-chain publication, scoped controllers and recovery integration |
| Discover | Signed cards, search, pagination, configurable directories | Registry proof/freshness verification and finalized reputation ranking |
| Execution | Real graph engine, separate per-job data, local models, limits, cancellation, interrupted-job review | Full checkpoint recovery drills and separately authorized compute routing |
| Transport | Encrypted store-and-forward, signed requests, expiry, replay protection, two-relay integration test | Deployed independent operators, relocation handshake and session rotation |
| Delivery | Encrypted bounded results, salted integrity commitment, explicit review | Large encrypted artifact storage, two-copy retention and dispute evidence sharing |
| KAI escrow | Compiled prototype with fixed beneficiaries, explicit acceptance, dispute splits, refunds and withdrawal credits | Real token authority tests, deployed contracts, complete paid quote/runtime integration |
| Spending | Prototype internal per-owner vault; cap, period, nonce, exposure and revocation checks | Paid SDK/UI grants and complete adversarial economic tests |
| Sponsorship | SDK policy checks exact operations, payee signature and pending resource caps | Dedicated funded account, service admission, simulation and reconciliation operator |
| Finality | Testnet chain adapter and transactional replay/rollback index | Actual RPC receipts, finalized dispatch and independent rebuild/outage evidence |
| Reviews | Prototype settled-job eligibility and revision commitments | Signed review content, index scoring and desktop UI |
| Product | Discover, My agents, Jobs, Earnings, Activity, settings, headless client | Funded hire/refund/dispute flows and real service earnings |
| Standards | Native versioned KAI protocol | Pinned A2A adapter and generated public SDK types; no x402 claim |
| Rewards | No subsidy or changed compute economics | Later explicitly funded bounties, outside initial release |

The first Test slice implements the private-service foundation. The minimum decentralized paid v1 gate described by the proposal is still open.
