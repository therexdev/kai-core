# KAI Core Beta 0.7.11

Earn and Network keep their last verified numbers visible while refreshing instead of replacing them with dashes. Read-only checks warm these pages while the Core window is visible, including while viewing other pages, and pause in the tray. Last-updated labels distinguish retained figures from fresh observations. Switching wallets, signing out, or selecting Local-Only clears the retained data. Stale network observations never enable model selection or claim a provider is currently ready.

Install the accompanying Brain, Connections, Workflows, Agent Network and Koinos Code updates from Plugins for the consistent sidebar design and the fix for delayed coding plans. Core retains the Windows updater verification fixes from 0.7.10.
